# Oracle Portfolio V2.6.0 - Vue d'ensemble du projet

## Objectif du projet
Oracle Portfolio V2.6.0 est une plateforme d'analyse financière avec interface de configuration complète. Elle permet :
- Analyse de portefeuilles avec données de 15 pays
- Configuration d'indicateurs, formules, régimes économiques et plugins
- Interface CRUD complète avec modal d'édition
- Dashboard et analytics avec graphiques interactifs

## Architecture technique
- **Architecture hybride** : Vite (frontend principal) + Next.js (API/SSR)
- **React 18.3.1** avec Radix UI pour les composants
- **Vite 6.3.5** pour le build et développement rapide
- **Tailwind CSS 4.1.7** pour le styling
- **date-fns 3.6.0** (version critique pour compatibilité)

## Fonctionnalités principales V2.6.0
- ✅ CRUD complet opérationnel (Créer, Éditer, Dupliquer, Supprimer)
- ✅ Modal d'édition avec pré-remplissage des données
- ✅ Validation JSON en temps réel
- ✅ Interface responsive moderne
- ✅ Sous-menus configuration : Indicateurs, Formules, Régimes, Plugins
